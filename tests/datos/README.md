# Datos de prueba

- `my_expenses_muestra.csv`: filas reales copiadas del dataset de Kaggle
  "My expenses data" (tharunprabu, licencia CC0), más una fila con una
  categoría inventada ("Pets") para probar las categorías sin mapear.
- `personal_transactions_muestra.csv`: filas **inventadas** con las mismas
  columnas que documenta el dataset "Personal Finance" (entrepreneurlife).
  Cuando tengan el archivo real, comprueben que sus categorías coincidan con
  el mapeo de `core/importadores/kaggle_personal_finance.py`.
